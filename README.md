# DungeonColony

**지하 콜로니 시뮬레이션** — 사방이 바위인 지하에 던전 코어를 세우고, 캐릭터들을 부려 바위를 캐며
기지를 넓히고, 더 깊은 층으로 탐험해 내려가는 게임.

세계의 기본 상태는 열린 굴이 아니라 꽉 찬 돌이라, 파는 것이 곧 확장이자 탐험이다.

---

## 무엇을 하는 게임인가

- **루프의 본류는 탐험이다.** 기지는 잠깐 들러 점검하는 곳이고, 탐험해 가져온 자원으로
  장비·하수인을 만들어 더 깊은 층으로 내려간다. 깊이가 곧 난도다.
- **자연은 찍어서 가져오고, 기지는 배정해서 캔다.** 야생 노드는 매장량만큼 내고 사라지고,
  기지 안의 작업은 캐릭터를 건물에 붙박아 돌린다(`H` 지휘소).
- **불빛 밖은 검다.** 하루는 밝기가 오르내리는 썰물·밀물이고, 캐릭터는 불빛이 닿는 만큼만 본다.
  안 보이는 곳은 전장의 안개로 덮인다.

### 캐릭터 둘

| 종류 | 데이터 | 조작 | 특징 |
|---|---|---|---|
| **방랑자** | `UnitData` | 직접 명령(우클릭) | 모든 작업. 소집(`R`)으로 싸울 태세에 붙든다 |
| **하수인** | `MinionData` | 자동 AI | 던전 코어의 소환진에서 소환. 스탯이 자라지 않는다 |

몸 종류가 무엇을 요구하는지 정한다 — 산 몸은 허기·피로, 골렘은 에너지, 해골은 사기.

## 주요 시스템

한 줄 요약이고, 근거와 수치는 `docs/`에 있다.

| 축 | 무엇을 하나 |
|---|---|
| **세계 · 층** | 한 변 4,096m 세계에 층 넷이 2×2로 놓인다(층 하나 2,048m). 층 사이는 기반암이고, 넘는 길은 통로와 핵 포탈뿐 |
| **바위와 굴** | 바위는 칸 단위 데이터(`RockMap`)이고 캔 자리만 다시 굽는다. 판 굴은 이틀 뒤 메워진다 |
| **스트리밍** | 지형 높이는 함수라 저장하지 않는다. 64m 청크가 카메라 둘레 5×5만 서고, 세우기·버리기는 프레임당 예산 안에서 |
| **길찾기** | 계층형 — 광역 그래프(`WideGraph`, 셀 안 연결 덩어리마다 노드)로 큰 길을 잡고, 40m 창 안에서 Theta\*로 실제 걸음을 낸다 |
| **멀리 있는 것** | 일정 반경 밖의 남의 캐릭터는 AI를 안 돌리고, 무리는 멀면 토큰으로 접힌다. 아무도 안 보는 습격은 결과만 계산한다 |
| **AI** | 행동 트리. 내 캐릭터는 고정 순서, NPC·적은 AI 패키지(목표 목록)가 트리를 짓는다. 습격대의 뜻은 `RaidLord`가 정한다 |
| **일감** | 작업 종류 가중치와 우선순위로 고르고, 같으면 가까운 것부터. 지휘소에서 캐릭터를 건물에 1~3순위로 배치한다 |
| **건설** | 청사진 → 자재 운반 → 시공. 외곽벽·얇은 벽, 바닥, 작업대 등급, 땅 고르기, 절벽 위 다리 |
| **전투** | 피해는 한 축(물리 3 + 원소 7). 부위별 체력·혈액·기절, 근접은 표적 둘레 자리를 나눠 선다. 진형 `F1~F5` |
| **세력** | 종족 · 세력 · AI 성향 · 역할 · 소지 · AI 패키지 — 여섯 축이 서로를 모른다. 관계는 방향별 |
| **포로 · 상인 · 상단** | 업기·가두기·회유·몸값 / 흥정 / 포탈 너머로 짐을 싣고 가는 상단 |
| **전력 · 연구** | 핵이 내는 힘을 먼저 지은 건물부터 받는다. 연구는 씬에 놓인 그래프 |

### 스탯

0–130 · 5단위 **27등급**(F- ~ SSS+) · **45개** 스탯. 켄시식으로 쓰면 자란다.

## 조작

| 키 | | 키 | |
|---|---|---|---|
| `I` | 인벤토리 | `B` | 건설 (`X` 철거) |
| `U` | 스탯 | `C` | 명령 |
| `P` | 무리 관리 | `V` | 구역(밭 · 저장) |
| `L` | 세력 | `H` | 지휘소(배치) |
| `O` | 자동운반 품목 | `T` | 상단 |
| `M` | 지도 | `R` | 소집 |
| `1~4` | 능동 능력 | `F1~F5` | 진형 |
| 좌/우클릭 | 선택 / 명령 | `Space` | 일시정지 |

카메라는 `WASD` · 중클릭 드래그 · 스크롤, `PageUp`/`PageDown`으로 내려다보기·낮은 각도.

## 개발 환경

- Unity 6.3 (6000.3.9f1)
- Wingman
- DOTween Pro

동작 확인은 에디터 Play Mode에서 한다. 컴파일만은 에디터 없이도 본다:

```
dotnet msbuild Assembly-CSharp.csproj -t:Build
dotnet msbuild Assembly-CSharp-Editor.csproj -t:Build
```

`.csproj`는 유니티가 만들기 때문에, 파일을 새로 만들거나 지운 직후에는 유니티에 포커스를 한 번 줘서
다시 만들게 해야 한다.

### 세계 굽기

세계는 저작 씬(`Assets/0_Scenes/World.unity`)에서 만들고 청크로 굽는다. 게임 씬은 `Scene1`이다.

```
DungeonColony → World → 1. Rebuild Underworld (전부)
```

굴이 어떻게 났는지는 `2. Preview Cave Map`이 PNG 한 장으로 보여준다.
