예시 모드 — 모드 폴더의 그림·모델이 실제로 실리는지 보여 주는 최소 예제

이 폴더는 검증용이다. **지워도 되고, 지우면 안의 아이템·레시피도 함께 사라진다.**
유니티를 설치하지 않고도 여기 있는 것만으로 그림과 모델이 게임에 실린다.

폴더 구조
---------
  ExampleMod/
    items/    *.json        아이템 정의
    recipes/  *.json        레시피 정의
    icons/    *.png         그림
    models/   *.obj *.mtl   모델 (+ 텍스처 PNG를 같은 폴더에)
  (icons/ models/ 라는 이름은 자유다 — JSON의 iconPath / modelPath가 정한다)

경로는 **이 폴더 기준 상대 경로**다
-----------------------------------
  "iconPath":  "icons/example_icon.png"
  "modelPath": "models/example_gem.obj"
확장자는 생략해도 된다. 폴더에서 못 찾으면 에셋 번들 → Resources 순으로 더 찾는다.
폴더 밖(`../`으로 빠져나가는 경로)은 해석하지 않는다.

모델 — .obj로 내보낼 것
-----------------------
게임이 읽는 건 **.obj**다. 블렌더·마야·3ds Max 모두 내보내기에서 OBJ를 고를 수 있다.
같은 폴더의 .mtl(재료)과 그것이 가리키는 텍스처 PNG까지 같이 읽는다.

  읽는 것: v / vt / vn / f(n각형 자동 삼각화) / usemtl(재료별 서브메시) / mtllib
  MTL:     newmtl · Kd(기본색) · d·Tr(투명도) · map_Kd(텍스처)

  **.fbx는 안 된다.** 유니티가 실행 중에 해석하지 못한다 — OBJ로 내보내면 된다.
  뼈대·애니메이션처럼 OBJ로 표현 못 하는 것이 필요할 때만 에셋 번들을 쓴다:
    에디터에서 모델·프리팹 선택 → DungeonColony → Build Mod AssetBundle → 이 폴더 지정
    JSON에는 "modelPath": "<번들 안의 에셋 이름>"
  번들은 유니티 버전·플랫폼마다 다르다. 다른 버전에서 구운 번들은 열리지 않는다.

크기는 파일 그대로 쓴다
-----------------------
게임이 알아서 줄이거나 키우지 않는다. 바닥에 떨어지는 소품은 **0.2~0.4 단위** 정도가
맞다(내장 폴백 모델이 0.25). 이 예제의 보석은 높이 0.44다.

식별자(id)를 쓸 것 — 이게 왜 중요한지 이 예제가 직접 겪었다
-----------------------------------------------------------
`id`를 비우면 표시명이 식별자가 된다. 표시명은 번역 대상이라 번역하는 순간 그걸 가리키던
참조가 끊기고, 모드끼리 이름이 겹치면 한쪽이 덮어써진다.

**실제로 물렸던 것**: 이 레시피의 재료를 처음엔 `"itemName": "구리 광석"`으로 적었는데
게임에 `구리 광석`이라는 이름의 아이템이 **둘**이었다(SO `Crystal_item` / JSON `copper_ore`).
창고에 든 건 앞엣것인데 이름으로 찾으니 뒤엣것이 잡혀서, 재료가 눈앞에 있는데도
"없음"이 떴다. 그래서 지금은 `"itemId": "Crystal_item"`으로 **식별자를 직접 가리킨다.**

→ 다른 콘텐츠를 가리킬 때는 `itemId` / `resultItemId`를 쓸 것.
   (`itemName`도 아직 동작하지만 레거시 조회라 콘솔에 경고가 뜬다.)

이 예제가 하는 일
-----------------
`예시 부적`을 추가하고 **용광로**에서 구리 광석 1개로 만들 수 있게 한다.
  · 작업대 목록에서 이 레시피를 고르면 결과 그림에 분홍/청록 원(icons/example_icon.png)이 뜬다.
  · 만든 것을 바닥에 버리면 노란 줄무늬 팔면체(models/example_gem.obj)가 놓인다.

  ※ **용광로는 작업대 8종 중 유일하게 연료를 쓴다.** 창고에 석탄이 없으면 폰이 작업대에
    붙은 채로 영원히 기다린다(콘솔: `[FuelJob] 연료 없음 —`). 제작이 안 끝나면 연료부터 볼 것.
